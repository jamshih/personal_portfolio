# Jun-Yuan portfolio

A zero-build, single-page personal website aimed at founder / YC-style applications.

## Preview locally

Open `index.html` in a browser.

## Deploy

This repository is ready for static hosting on Vercel. No build command is required; the root `index.html` is the site entry point.

## Notes

- The portfolio keeps GitHub secondary rather than treating public repository count as the main credibility signal.
